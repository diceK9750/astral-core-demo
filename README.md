# ASTRAL CORE

光・音・タッチで「未来の AI コアとの接続」を体験するブラウザデモ。

**公開 URL：<https://dicek9750.github.io/astral-core-demo/>**

| 操作 | 反応 |
| --- | --- |
| 中央コア／「接続する」をタップ | 接続し、音声を有効化 |
| 接続後にコア付近をタップ | 光の伝播と音階の反応 |
| 長押し → 離す | エネルギーを凝縮して放出 |
| ダブルタップ | NOVA |
| OVERDRIVE | 9 秒間の強化演出。STABILIZE で途中解除 |
| 右上の音声ボタン | サウンドのオン／オフ |

PC はクリックでも同じ操作ができます。Tab でボタンを選択し、Enter で実行できます。コアにフォーカス中の Space は長押しチャージに対応します。ボタンや入力欄にフォーカスしていない場合、Space は OVERDRIVE、N は NOVA、Escape は OVERDRIVE の解除です。

## 実装と対応

デモ本体は `index.html` だけで動作します。Canvas 2D・CSS・Web Audio によるプロシージャル描画と合成音で、追加ライブラリ・CDN・外部素材・ビルド作業は不要です。読み込み後の外部通信、広告、トラッキング、個人情報取得はありません。AI 接続・解析・数値表示は演出で、実際の AI 推論やサーバー接続は行いません。

iPhone／Android／PC のブラウザを想定し、縦横画面、safe-area、動的ビューポートに対応しています。描画解像度・演出密度を調整し、バックグラウンドでは描画と音声を停止します。OS の `prefers-reduced-motion` 設定で動きを軽減します。

音はユーザー操作後に開始します。音量、消音設定、ブラウザ側の音声制限によって聞こえない場合があります。復帰後は次の操作で音声を再開します。振動は Vibration API が利用可能で、ブラウザが許可する場合のみ動作します。API のない環境では振動しません。端末・OS・ブラウザの組み合わせによる差があり、実機の聴感・触覚・性能を一律に保証するものではありません。

## ローカル確認

`index.html` を直接開いて体験できます。QA ページの同一オリジン検査は、リポジトリのルートで HTTP サーバーを起動して確認します。

```sh
python3 -m http.server 8000
```

デモ：<http://localhost:8000/> ／ QA：<http://localhost:8000/tests/preview.html>

`tests/preview.html` は 320／375／390／430 px 幅、横画面、1920 × 1080 の表示領域で同じデモを表示する受動的な検査ページです。操作を自動実行せず、はみ出し、主要ボタンの配置・サイズ・重なり、数値異常、読み込み完了後の未処理例外を検査します。起動前の例外、Console、実機の safe-area、聴感・触覚は別途確認が必要です。

ソースの構文、重複 ID、主要ボタン、外部依存と、操作・音声開始制御・中断復帰を確認します（Node.js、追加パッケージ不要）。

```sh
node tests/check-source.cjs
node tests/interaction.cjs
```

操作テストは DOM・Canvas・音声 API のモックを使ったロジック検査です。実ブラウザの描画・速度、音質、スマートフォン実機の検証を代替しません。
